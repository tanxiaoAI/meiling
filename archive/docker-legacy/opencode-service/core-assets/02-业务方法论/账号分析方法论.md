# 账号分析方法论

## 1. 文档目标

本方法论文档用于定义“如何分析一个账号”。

这里的账号分析，是通过对其商业模式、内容证据和账号整体心智的判断，回答以下问题：

- 这个号到底是什么
- 这个号为什么能成立
- 这个号是如何用内容连接商业的
- 这个号哪些部分值得学习，哪些部分不应照搬

本方法论的主要用途有三类：

- 对标账号研究
- 优质账号筛选
- 为05-我方资料/我方账号定位、内容策略和产品承接提供参考

账号分析的输出，是为了形成可判断、可比较、可复用的结论。

## 2. 分析原则

- 证据先行：所有账号判断都应尽量由模式层和内容层证据支撑，避免凭印象下结论
- 分层判断：模式层、内容层、账号层、启发层各自解决不同问题，不混用边界
- 先描述后判断：先提取证据，再收束为账号结论
- 质量与适配分开：一个账号可以很强，但不一定适合我学习
- 概要与详细分开：概要分析只做初筛和导航，详细分析才形成正式判断

## 3. 核心层级

### 3.1 总览

| 层级  | 核心问题                         | 主要输入                  | 主要输出                                        | 作用               |
| --- | ---------------------------- | --------------------- | ------------------------------------------- | ---------------- |
| 模式层 | 这个号怎么赚钱                      | 账号基础资料、人工背景说明、产品服务信息  | 目标付费用户、产品服务体系、转化路径、商业模式摘要                   | 建立商业边界           |
| 内容层 | 这个号长期在讲什么，用什么方式吸引人、建立信任、连接商业 | 内容列表、内容样本、基础资料、人工先验说明 | 核心议题、目标问题、价值表达方式、用户吸引机制、信任建立机制、认知一致性、商业连接线索 | 从内容中提取可支撑账号判断的证据 |
| 账号层 | 这个号到底是什么，为什么成立               | 模式层输出、内容层输出、必要基础资料    | 账号定位、目标用户画像、价值主张、人设风格、差异化、成立逻辑、关键依赖         | 基于证据判断账号本质       |
| 启发层 | 这个号对我有什么用                    | 模式层、内容层、账号层结论，以及我方当前概要  | 可借鉴项、不可复制项、适配性判断、定位启发、内容策略启发、优先行动建议         | 将对标研究转成我方动作      |

### 3.2 模式层

| 字段     | 定义                            | 需要回答的问题                                     |
| ------ | ----------------------------- | ------------------------------------------- |
| 目标付费用户 | 真正会为这个账号产品或服务付费的人群            | 谁在付钱？这些人为什么愿意付钱？                            |
| 产品服务体系 | 这个账号提供的产品或服务组合，包括卖什么、分几层、如何交付 | 他卖的是信息、框架、陪跑、顾问、圈层、资源，还是其他？有哪些价格带？各自承担什么作用？ |
| 转化路径   | 用户从看到内容到成交的承接路径               | 用户是怎么被吸引、进入、筛选、成交、复购或升级的？                   |
| 商业模式摘要 | 对前三项的压缩总结，不单独展开新分析            | 这个号本质上是靠什么赚钱的？                              |

模式层的关键不是把所有商业细节都猜全，而是在有限信息下，先建立一个可被后续内容证据验证或修正的商业边界。

### 3.3 内容层

| 字段     | 定义                  | 需要回答的问题                              |
| ------ | ------------------- | ------------------------------------ |
| 核心议题   | 这个号长期反复在讲什么主题       | 这个号主要在聊哪几类问题？哪些议题是高频主线？              |
| 目标问题   | 这个号主要帮用户解决什么问题      | 它主要回应用户哪些痛点、困惑、焦虑、目标？                |
| 价值表达方式 | 它主要用什么内容方式传递价值      | 它更常用教程、观点、案例、复盘、清单、规则解读，还是情绪、身份认同？   |
| 用户吸引机制 | 它靠什么让用户愿意点进来和继续看    | 用户主要是被功利结果、反常识、冲突、身份认同、情绪共鸣、信息差吸引吗？  |
| 信任建立机制 | 它靠什么让用户觉得“这人有东西”    | 它主要靠经历、案例、数据、权威、逻辑、结果、口碑，还是人格魅力建立信任？ |
| 认知一致性  | 看这些内容是否共同指向一个稳定账号心智 | 这些内容合在一起，是否让用户形成稳定印象，还是东一榔头西一棒槌？     |
| 商业连接线索 | 内容如何自然连到产品、服务或成交    | 内容有没有把用户往群、课、顾问、私域、线下课等方向承接？         |

内容层的主要分析维度如下：

- 普遍性：这个特征在账号内容中出现得是否广泛，是少数内容才有，还是大量内容都有
- 显著性：这个特征是否足够突出，足以影响用户感知
- 代表样本：哪些内容最能体现这个特征，可以作为证据样本

内容层的职责是提证据，不直接下账号本质结论。

### 3.4 账号层

| 字段     | 定义                 | 需要回答的问题                           |
| ------ | ------------------ | --------------------------------- |
| 账号定位   | 判断这个号在用户心中到底扮演什么角色 | 用户会把它当成什么号来看待？                    |
| 目标用户画像 | 这个号实际吸引和服务的是谁      | 真正被吸引、被转化、被留下来的是哪类人？              |
| 价值主张   | 这个号向用户持续承诺的核心价值    | 用户为什么要关注它、相信它、持续看它？               |
| 人设风格   | 判断它以什么人格形象被感知      | 它更像老师、顾问、同行、陪跑者、观察者，还是其他？         |
| 差异化    | 这个号和同类号相比最主要的区别    | 它凭什么不是“另一个同类号”？                   |
| 成立逻辑   | 这个号为什么能成立的核心原因     | 是因为认知强、案例强、表达强、产品承接强，还是这些因素的组合？   |
| 关键依赖   | 这个号成立最依赖什么条件       | 它最依赖认知深度、表达能力、经历、案例、口碑、交付能力，还是其他？ |

账号层的主要分析维度如下：

- 清晰度：这个判断是否明确、稳定、不打架
- 支撑度：这个判断是否有足够的模式层和内容层证据支撑

### 3.5 启发层

| 字段     | 定义                         | 需要回答的问题               |
| ------ | -------------------------- | --------------------- |
| 可借鉴项   | 这个对标号中值得我学习的核心做法           | 这个号最值得学的是什么？          |
| 不可复制项  | 这个号的优势里，我很难直接复制的部分         | 这个号哪些成立条件是我没有的？       |
| 适配性判断  | 这个号的做法与我当前目标、能力、产品、阶段是否匹配  | 这个号适不适合我学？适合学多少？      |
| 定位启发   | 这个对标号对05-我方资料/我方账号定位的启发            | 我应该借它的哪种定位思路？         |
| 内容策略启发 | 这个对标号对05-我方资料/我方内容选题、表达、栏目和内容机制的启发 | 我后续内容该怎么做得更对？         |
| 优先行动建议 | 基于以上判断，最值得先做的动作            | 如果只做 1 到 3 个动作，我先做什么？ |

## 4. 标准分析流程

账号分析的标准流程如下：

| 步骤         | 目标              | 输入                     | 输出                                          | 方法                 |
| ---------- | --------------- | ---------------------- | ------------------------------------------- | ------------------ |
| 1. 模式层初判   | 先判断这个号怎么赚钱      | 主页资料、商品或服务信息、简介、你已知的信息 | 目标付费用户、产品服务体系、转化路径、商业模式摘要                   | 先建立商业边界，不追求一次就完全正确 |
| 2. 内容层提证据  | 看这个号长期通过内容在传递什么 | 内容列表、内容样本、必要时参考数据、人工说明 | 核心议题、目标问题、价值表达方式、用户吸引机制、信任建立机制、认知一致性、商业连接线索 | 只提证据，不下账号本质结论      |
| 3. 账号层综合判断 | 把模式和内容收束成账号认知   | 模式层输出、内容层输出            | 账号定位、目标用户画像、价值主张、人设风格、差异化来源、成立逻辑、关键依赖       | 用前两层推导，不重复罗列现象     |
| 4. 启发层映射我方 | 回到我方能学什么、该做什么   | 账号层输出，以及我方目标、产品、能力、约束  | 可借鉴项、不可复制项、适配性判断、定位启发、内容策略启发、优先行动建议         | 不再分析对方，转而服务我方决策    |

## 5. 常见输入材料与作用

账号分析不要求每次都输入完全一致，但常见输入材料建议尽量标准化。这样既方便人工整理，也方便后续通过 AI、表格和自动化流程衔接。

| 输入项 | 说明 | 主要作用 | 更偏支持哪一层 |
| --- | --- | --- | --- |
| 图片说明 | 商品或服务截图、价格页、服务说明页、报名页、社群截图、主页截图、封面截图等 | 辅助判断卖什么、怎么分层、如何交付，以及主页气质、封面风格、栏目感和账号整体呈现 | 模式层、内容层、账号层 |
| 内容列表 | 标题、内容类型、点赞、收藏、评论、分享、发布时间、内容概要等 | 用来观察全局议题、数据分布、内容支柱和初步表现 | 内容层 |
| 人工先验说明 | 购买体验、产品信息、群体感受、是否有私域、社群、线下课等 | 补充前台看不到的商业信息，辅助模式层判断 | 模式层、启发层 |
| 我方当前概要 | 我想做的账号方向、产品或服务、目标用户、核心能力等 | 用于把对标分析结果转成对我有用的启发建议 | 启发层 |

使用时建议遵循以下原则：

- 没有全部输入也可以分析，但要明确哪些结论是低置信度判断
- 图片说明和人工先验说明越完整，模式层越稳
- 内容列表越完整，内容层越容易看出主线和分布
- `05-我方资料/我方当前概要.md` 不是账号分析必填项，但没有它，启发层只能输出通用建议

## 6. 两种执行模式

### 6.1 基本定义

账号分析只有一套底层方法论，但存在两种执行模式：

- 概要分析：低成本快速判断，用于初筛和导航
- 详细分析：证据更充分、输出更完整，用于深挖和提炼可复用策略

两者不是两套不同的方法，而是同一套方法在不同输入条件和不同目标下的执行深度差异。

### 6.2 概要分析

概要分析适用于以下场景：

- 快速筛选对标账号
- 批量初看多个账号
- 判断一个账号是否值得进入详细分析

概要分析的特点：

- 输入更轻
- 速度更快
- 结论更粗颗粒
- 输出性质为初步判断，不作为最终结论

概要分析的核心任务不是把账号讲透，而是回答两个问题：

- 这个号大概是什么类型
- 这个号值不值得进一步深挖

### 6.3 详细分析

详细分析适用于以下场景：

- 已确认值得研究的对标账号
- 需要提炼可借鉴的定位和内容策略
- 需要形成正式方法论结论或案例沉淀

详细分析的特点：

- 输入更充分
- 字段更完整
- 证据要求更高
- 输出可直接进入案例库或启发层使用

### 6.4 两种模式的关系

系统默认建议先做概要分析，再决定是否进入详细分析。

原因如下：

- 大多数账号不值得一开始就投入高成本深挖
- 概要分析更符合真实使用习惯
- 先筛选，再深挖，整体效率更高

但需要明确以下规则：

- 概要分析的作用是导航，不是最终定论
- 详细分析可以参考概要分析提出的疑点、方向和待验证点
- 详细分析不得把概要分析的初步结论直接当成证据
- 详细分析必须回到更原始的输入材料重新判断

一句话说，概要分析负责“筛选与导航”，详细分析负责“正式判断与提炼”。

### 6.5 进入详细分析的条件

一个账号是否值得进入详细分析，通常看以下几个维度：

- 质量高：内容与商业整体成熟，有研究价值
- 适配度高：与我方目标、产品、能力和阶段有较强关联
- 商业模式值得研究：承接方式、产品结构或转化路径有参考价值
- 内容机制明显：选题、表达、信任建立或转化机制具有清晰特征

满足其中一部分条件，就可以进入详细分析，不要求所有条件同时满足。

## 7. 深度研究时的补充维度

前面的主框架，适合大多数账号分析任务。如果要做更深入的研究，可以加入以下补充维度。

### 7.1 前台可见的补充维度

| 元素      | 说明                                                                                |
| ------- | --------------------------------------------------------------------------------- |
| 更细的模式分析 | 产品价格带和价格梯度；免费内容和付费产品之间的关系；是否存在低价引流品、中价成交品、高价利润品；广告合作频率和品牌类型；账号更偏品牌号、IP 号、销售号还是转化号 |
| 更细的账号分析 | 账号名字、头像、简介的设计逻辑；主页置顶内容在传递什么；沟通姿态是平视、仰视、俯视还是陪伴型；人设是天然形成还是明显设计过；差异化来自身份、观点、视觉还是表达气质 |
| 更细的内容分析 | 高频爆款选题模板；常见标题公式；开头常用话术；冲突点、反转点、记忆点；信息密度；更偏“看完爽”还是“看完有用”；更适合推荐流还是搜索流；栏目化程度和系列化能力   |
| 用户反馈分析  | 评论区高频问题；评论区用户画像倾向；用户为什么点赞、收藏、争论；热门评论是否反映真实需求和情绪；用户把这个账号当作工具、陪伴、娱乐还是消费决策参考         |
| 平台适配分析  | 这个账号为什么适合当前平台；同样内容换个平台是否还成立；它更依赖平台推荐、搜索，还是主页与私域承接；平台机制是否放大了它的内容形式                 |

### 7.2 需要额外信息的补充维度

很多更深的判断，不能只靠前台账号信息完成，通常还需要结合外部信息，例如：

- 账号主理人背景
- 团队规模和生产方式
- 是否投流
- 是否有供应链或线下资源
- 私域承接能力
- 实际产品能力
- 商业合作情况
- 运营周期和关键增长节点

这些内容不属于账号分析的标准必选输入，而属于“深度研究时的补充情报”。
