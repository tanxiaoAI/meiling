# 数据结构规范

## 1. 文档定位

这份文档只定义 `07-记录表/` 的数据结构。

它主要回答 4 个问题：

- 每张表承接什么对象
- 每张表一行代表什么
- 每张表的主键是什么
- 每个字段承接什么信息

它不负责下面这些内容：

- 业务判断标准
- 流程执行顺序
- 什么时候读取、什么时候回写
- 缺资料时如何继续
- 后续新增字段如何审批

上面这些内容，分别优先看 `02-业务方法论/` 和 `03-执行流程/`。

## 2. 适用范围

本规范默认覆盖 `07-记录表/` 下当前 8 张表：

- `账号库.csv`
- `我方账号库.csv`
- `内容库.csv`
- `我方内容库.csv`
- `选题库.csv`
- `内容特征库.csv`
- `内容特征组合库.csv`
- `我方内容特征验证记录.csv`

## 3. 结构规则

### 3.1 表级规则

- 一张表只承接一种主对象或一种主记录用途
- 一行只代表一个最小稳定对象，不混装多个对象
- 每张表都应有稳定主键，不轻易改名或重分配
- 记录表只存结构化索引、状态、路径和简短摘要，不存长篇正文

### 3.2 字段规则

- `ID` 字段：用于唯一标识对象或记录，同一对象在系统内尽量保持同一叫法
- 对标账号相关唯一识别：固定使用 `平台 + 账号ID`，不再用昵称判断是不是同一个账号
- `路径` 字段：用于承接结果文件或资料文件的位置，不承接临时对话结论
- `状态` 字段：用于承接对象所处阶段，优先使用稳定短词
- `时间` 字段：同一字段在同一张表内保持一致粒度，不混用日期和相对时间
- `备注` 字段：只放简短补充信息，不替代正式字段

## 4. 表分类总表

| 表名 | 主键 | 一行代表什么 | 主要用途 |
| --- | --- | --- | --- |
| `账号库.csv` | `平台 + 账号ID` | 一个对标账号 | 管理对标账号的基础信息、样本路径和分析状态 |
| `我方账号库.csv` | `我方账号ID` | 一个我方账号 | 管理我方账号的基础信息、经营材料和诊断状态 |
| `内容库.csv` | `内容ID` | 一篇对标内容 | 管理对标内容的基础数据、正文路径和分析路径 |
| `我方内容库.csv` | `我方内容ID` | 一篇我方内容 | 管理我方内容实例、生产结果、发布数据与复盘结果 |
| `选题库.csv` | `选题ID` | 一个选题 | 管理选题从灵感到复盘的生命周期 |
| `内容特征库.csv` | `记录ID` | 一个特征在一篇内容中的一次出现 | 管理特征记录及验证状态 |
| `内容特征组合库.csv` | `组合ID` | 一个稳定组合 | 管理组合定义、适用条件和验证状态 |
| `我方内容特征验证记录.csv` | `验证记录ID` | 一次明确验证行为 | 管理我方对特征或组合的验证结论 |

## 5. 各表规范

### 5.1 `账号库.csv`

- 表作用：追踪对标账号基础信息与研究材料入口
- 主键：`平台 + 账号ID`
- 一行代表：一个对标账号

| 字段名 | 含义 | 必填级别 | 说明 |
| --- | --- | --- | --- |
| `账号ID` | 平台原生账号ID | 必填 | 与 `平台` 组合后唯一识别一个账号 |
| `昵称` | 账号显示名称 | 必填 | 展示字段，不作为唯一识别字段 |
| `平台` | 账号所在平台 | 必填 | 例如小红书、抖音 |
| `简介` | 主页简介 | 选填 | 可从主页资料补录 |
| `性别` | 账号主体性别 | 选填 | 无法确认可留空 |
| `关注数` | 关注数 | 选填 | 可阶段性为空 |
| `粉丝数` | 粉丝量 | 选填 | 可阶段性为空 |
| `获赞数` | 累计获赞量 | 选填 | 可阶段性为空 |
| `标签` | 账号标签或关键词 | 选填 | 用于快速判断定位 |
| `主页链接` | 账号主页链接 | 建议必填 | 便于回看 |
| `图片说明路径` | 主页长截图或商品图说明文件路径 | 选填 | 资料入口字段 |
| `内容列表路径` | 内容列表 CSV 或索引路径 | 建议必填 | 样本入口字段 |
| `人工先验说明路径` | 人工整理的先验判断路径 | 选填 | 资料入口字段 |
| `是否已概要分析` | 是否已完成概要分析 | 必填 | 建议写 `是 / 否` |
| `是否已详细分析` | 是否已完成详细分析 | 必填 | 建议写 `是 / 否` |
| `质量判断` | 对账号研究价值的阶段判断 | 选填 | 例如值得研究、一般、可放弃 |
| `适配判断` | 对我方参考价值的阶段判断 | 选填 | 例如高适配、中适配、低适配 |
| `备注` | 其他简短说明 | 选填 | 不承接长结论 |
