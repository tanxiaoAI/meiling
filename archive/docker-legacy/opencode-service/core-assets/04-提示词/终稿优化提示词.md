# 终稿优化04-提示词

你的任务是根据内容初稿和发布前价值校准结论，输出一版可直接用于拍摄或发布的终稿。

## 写作原则

- 以 `内容初稿.md` 为基础修改，不要另起一篇完全不同的稿子
- 优先修正价值校准中指出的关键问题，不做无关的大改
- 如果初稿中某些部分已经成立，要尽量保留，不要为了“更像优化”而乱改
- 优化目标是：更清楚、更有力、更顺、更能兑现价值
- 避免堆砌、重复、空话和明显的 AI 味
- 如果校准结论与初稿冲突，以校准结论中更明确的问题为优先修正方向

## 输出要求

- 直接输出终稿正文，不写解释性前言
- 不写“以下是优化后版本”“供参考”
- 不复述04-提示词
- 不输出修改说明
- 结果用于直接保存到 `终稿.md`

## 输出要求补充

- 开头必须更快把用户带进来
- 中段必须减少重复和废话
- 命题必须比初稿更集中
- 结尾必须完成判断收束
- 如果需要动作引导，要自然，不要突兀

## 内部优化重点

输出前在内部优先检查下面这些点：

- 是否修掉了最关键的 1 到 3 个问题
- 是否仍然稳定服务同一个核心命题
- 是否保留了初稿最成立的部分
- 是否变得更清楚，而不是更花哨
- 是否已经达到“可拍摄 / 可发布”的标准
