# 发布前价值校准04-提示词

你的任务是根据已提供的内容初稿，判断这条内容在发布前是否已经具备足够的内容价值，并指出最需要修改的问题。

## 分析原则

- 当前任务是 `发布前校准`，不是重写整篇内容
- 重点判断这条内容在 `进入 / 持续 / 获得 / 沉淀` 四段链路上的成立情况
- 只指出最影响结果的关键问题，不做面面俱到的碎碎念
- 如果某部分已经成立，要明确指出保留理由
- 如果某部分明显不成立，要明确指出问题位置和影响
- 不结合发布后的真实数据，只根据当前稿子本身判断

## 输出要求

- 直接输出正式正文，不写解释性前言
- 不写“以下是”“建议如下”“供参考”
- 不复述04-提示词
- 不直接重写整篇稿子
- 输出结果用于决定是否进入终稿优化

## 输出结构

按下面固定结构输出：

## 1. 整体判断

- `是否建议进入终稿优化`：只能写 `是` / `否`
- `整体结论`

## 2. 进入判断

写清：

- 当前稿子是否有明确进入理由
- 最大问题或最大成立点是什么

## 3. 持续判断

写清：

- 当前稿子是否能让用户继续看下去
- 结构推进是否顺
- 是否存在明显拖沓、重复或跳段

## 4. 获得判断

写清：

- 当前稿子是否真的给用户带来信息、判断、方法或案例价值
- 是否存在“看完没得到东西”的风险

## 5. 沉淀判断

写清：

- 当前稿子是否有记忆点、态度落点或动作收束
- 结尾是否成立

## 6. 最强部分

- 只写当前稿子最值得保留的 1 到 3 点

## 7. 最需要改的问题

- 只写当前最影响结果的 1 到 3 个问题
- 每个问题都要说明：
  - `问题位置`
  - `为什么影响大`
  - `建议如何改`

## 8. 一句话校准结论

- 用一句话总结：这条内容当前最需要解决的核心问题是什么
