# 选题分析04-提示词

你的任务是根据已提供的选题材料，输出一份可直接进入 `内容生产流程` 的选题定稿。

## 写作原则

- 只根据已提供的材料判断，不擅自补充用户未确认的信息
- 重点先判断 `该不该做`，再判断 `如果做，应该怎么定义`
- 以 `05-我方资料/我方当前概要.md` 为我方统一输入，不再展开读取更上游文档
- 参考特征只用于辅助判断，不要把参考样本当成唯一标准答案
- 如果参考内容不足或信息不足，要明确边界，不要硬判
- 输出结果要服务后续 `内容生产流程`，不要提前生成框架、初稿或终稿

## 输出要求

- 直接输出正式正文，不写解释性前言
- 不写“以下是”“建议如下”“供参考”
- 不复述04-提示词
- 不混入对话过程
- 不输出流程步骤、输入检查、补资料建议
- 结果用于直接写入选题分析记录，或回写 `选题库.csv` 相关字段

## 输出结构

按下面固定结构输出：

## 1. 选题名称

- 写清当前分析的是哪个题
- 如有必要，可用一句话补足题意

## 2. 是否建议做

- 只能写：`建议做` / `暂缓` / `不建议做`

## 3. 判断理由

写清：

- 这个题是否符合我方当前方向
- 是否服务我方当前最想吸引的用户
- 是否击中真实痛点、真实兴趣或真实困境
- 是否值得当前阶段优先做

## 4. 目标用户

写清：

- 这条内容主要写给谁
- 哪些人可能会看，但不是优先服务对象

## 5. 核心痛点

写清：

- 这条内容最主要承接哪个问题
- 这个问题为什么值得用户停下来

## 6. 收益承诺

写清：

- 用户看完最有希望得到什么
- 这个承诺为什么成立

## 7. 核心命题

写清：

- 这条内容最后最想让用户相信什么
- 命题必须是一个明确判断，不是泛泛话题

## 8. 切口

写清：

- 这条内容从哪个角度切进去
- 为什么这个角度更适合当前阶段

## 9. 建议内容类别

写清：

- 更适合做成 `教程型 / 观点型 / 资料型 / 案例型 / 复盘型 / 清单型 / 故事型 / 混合型` 中的哪一种
- 如为混合型，说明主次关系

## 10. 建议表达方向

写清：

- 更适合怎么讲
- 更适合强调认知、方法、资料，还是案例

## 11. 建议借用特征

写清：

- 当前最值得借用的 1 到 3 个特征
- 优先写与 `主题 / 命题 / 切口 / 收益承诺` 直接相关的特征

## 12. 建议借用组合

写清：

- 当前最值得借用的 1 到 2 个特征组合
- 说明它们主要服务 `进入 / 获得`

## 13. 建议避开风险

写清：

- 当前最容易出现的 1 到 3 个错位
- 例如：命题过大、切口过散、收益承诺过虚、目标用户过宽

## 14. 是否进入内容生产

- 只能写：`是` / `否`
- 如果写 `否`，原因必须已经在前文体现，不要新增额外章节
