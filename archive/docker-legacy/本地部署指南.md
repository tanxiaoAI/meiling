
## 故障排查

### 问题 1：Docker 未安装或未启动

**解决方法**：
1. 安装 Docker Desktop for Mac
2. 下载地址: https://www.docker.com/products/docker-desktop
3. 安装后启动 Docker Desktop

### 问题 2：端口被占用

如果 3000 或 5432 端口被占用：

```bash
# 修改端口映射
# 编辑 docker-compose.test.yml
# 将 "3000:3000" 改为 "3001:3000"
# 将 "5432:5432" 改为 "5433:5432"
```

### 问题 3：服务启动失败

```bash
# 查看详细日志
docker-compose -f docker-compose.test.yml logs

# 重新构建
docker-compose -f docker-compose.test.yml build --no-cache

# 重新启动
docker-compose -f docker-compose.test.yml up -d
```

### 问题 4：核心资产未复制

如果核心资产目录为空：

```bash
# 手动复制
cd /Users/tanxiao/Desktop/AI自媒体系统开发/saas-platform/opencode-service

mkdir -p core-assets
cp -r ../../skill文件/01-系统层 core-assets/
cp -r ../../skill文件/02-业务方法论 core-assets/
cp -r ../../skill文件/03-执行流程 core-assets/
cp -r ../../skill文件/04-提示词 core-assets/

# 重新构建镜像
cd ../deployment/zeabur
docker-compose -f docker-compose.test.yml build
docker-compose -f docker-compose.test.yml up -d
```
