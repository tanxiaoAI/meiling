# 系统初始化校验流程

## 1. 目标

在进入任一业务流程前，先完成运行时上下文、目录结构和基础文件可用性的系统校验。

## 2. 固定读取

- `../_runtime/context.json`

## 3. 校验范围

- 校验 `account_slug`、`workspace_root`、`pack_root`、`pack_name`、`pack_version` 是否存在
- 校验 `${WORKSPACE_ROOT}` 与 `${PACK_ROOT}` 是否可访问
- 校验 `${PACK_ROOT}/01-系统层`、`${PACK_ROOT}/02-业务方法论`、`${PACK_ROOT}/03-执行流程`、`${PACK_ROOT}/04-提示词` 是否存在
- 校验 `${WORKSPACE_ROOT}/05-我方资料`、`${WORKSPACE_ROOT}/06-沉淀结论`、`${WORKSPACE_ROOT}/07-记录表`、`${WORKSPACE_ROOT}/08-对标账号`、`${WORKSPACE_ROOT}/09-对标内容` 是否存在

## 4. 初始化规则

- 若业务流程要求的资料文件不存在，由系统在对应目录创建空白文件
- 若当前账号的隐藏方法论包不存在，由系统先完成包同步，再进入业务流程
- 若 `context.json` 缺失或字段不完整，停止业务流程并返回系统错误
