# 内容框架生成04-提示词

你的任务是根据已确认的选题定稿，生成一份可直接进入初稿撰写的内容框架。

## 写作原则

- 以已确认的 `目标用户 / 核心痛点 / 收益承诺 / 核心命题 / 切口` 为准
- 只生成结构，不直接展开成长篇正文
- 优先保证结构能承接命题，而不是为了热闹堆太多段落
- 参考特征和组合只用于增强结构成立性，不要机械照抄
- 如果某一部分信息不足，只保守表达，不要硬补设定
- 框架要服务后续初稿生成，结构要清楚、可展开、可删改

## 输出要求

- 直接输出正式正文，不写解释性前言
- 不写“以下是”“供参考”“你可以”
- 不复述04-提示词
- 不混入对话过程
- 不写长段成稿正文
- 输出结果用于直接保存到 `内容框架.md`

## 输出结构

按下面固定结构输出：

## 1. 内容定位

写清：

- `目标用户`
- `核心痛点`
- `收益承诺`
- `核心命题`
- `切口`
- `内容类别`
- `表达方向`

## 2. 标题方向

给出：

- `标题方向`
- `标题思路`

要求：

- 只写 1 个当前主标题方向
- 如有必要，可补 1 到 2 个备选表达

## 3. 开头设计

写清：

- `开头目标`
- `开头方式`
- `前两段要完成什么`

要求：

- 重点回答怎么把用户拉进来
- 不直接写成长篇开头正文

## 4. 主体结构

按顺序拆成 3 到 5 个结构段。

每段都写：

- `段落名称`
- `这一段要回答什么`
- `这一段的关键信息`
- `这一段与上一段如何衔接`

要求：

- 结构必须围绕命题推进
- 每一段都要有信息增量
- 不要只写空泛标题

## 5. 收束方式

写清：

- `结尾目标`
- `结尾收束句方向`
- `是否需要动作引导`

要求：

- 先收束判断，再考虑动作
- 如果不适合做强 CTA，就明确写弱收束

## 6. 重点借用项

写清：

- `本框架优先借用的特征`
- `本框架优先借用的组合`

要求：

- 只写最重要的 1 到 3 项
- 说明它们主要服务哪一段链路

## 7. 结构风险提醒

写清：

- 当前框架最可能出问题的 1 到 3 个点
- 例如：开头太慢、主体太散、命题不够集中、结尾太弱
