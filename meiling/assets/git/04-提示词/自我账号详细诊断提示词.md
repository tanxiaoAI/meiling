# 自我账号详细诊断04-提示词

你的任务是根据已提供的标准答案、当前账号实际表现和本轮分层诊断结论，输出一份自我账号详细诊断结论。

## 分析原则

- 当前任务是 `日常校准`，不是重新定义商业模式或自媒体模式
- 必须以 `我方商业模式.md` 和 `我方自媒体模式.md` 为判断标准
- 重点诊断 `模式层 / 账号层 / 内容层`
- 优先回答“有没有跑成我想要的样子”，其次才回答“做得够不够好”
- 只收束当前最关键的 1 到 3 个问题，不罗列所有小问题
- 如果信息不足，要明确写 `信息不足`，不要硬判
- 默认服务对话结论，不额外生成正式报告

## 输出要求

- 直接输出正式正文，不写解释性前言
- 不写“以下是”“供参考”“建议如下”
- 不复述04-提示词
- 不输出流程步骤
- 不混入对话过程
- 结果用于当前轮自我账号详细诊断的对话收束

## 输出结构

按下面固定结构输出：

## 1. 本轮诊断目标

写清：

- 这次主要在校准什么
- 本轮诊断范围是什么

## 2. 模式层诊断

写清：

- `当前一致的部分`
- `当前偏差最大的部分`
- `模式层结论`

要求：

- 核心回答：当前账号有没有在服务正确的商业路径

## 3. 账号层诊断

写清：

- `当前一致的部分`
- `当前偏差最大的部分`
- `账号层结论`

要求：

- 核心回答：当前账号在用户心里，是否跑成我想要的样子

## 4. 内容层诊断

写清：

- `当前一致的部分`
- `当前偏差最大的部分`
- `内容层结论`

要求：

- 核心回答：当前内容有没有真正支撑账号心智和商业承接

## 5. 当前最关键的问题

- 只写 1 到 3 个
- 每个问题都写清：
  - `问题是什么`
  - `主要卡在哪一层`
  - `为什么它最影响当前账号成立`

## 6. 优先调整建议

- 只写最优先的 1 到 3 条
- 每条都写清：
  - `建议动作`
  - `优先级`
  - `为什么先改这个`

## 7. 结果分流建议

写清：

- 哪些结论已经足够明确，可以直接采用
- 哪些结论更适合先写入 `我方调整候选池.md`

## 8. 一句话诊断结论

- 用一句话写清：当前这个号最关键的校准任务是什么
