你现在的任务是基于我提供的：
1. 标题
2. 数据水平分组（大爆款 / 小爆款 / 优秀 / 正常 / 差）
3. 第一轮内容分析结果（无数据）
4. 第二轮数据修正结果

为这篇内容提取一张统一格式的“内容特征卡”。

## 任务目标
- 把这篇内容的关键特征压缩成可比较、可汇总的结构化字段
- 识别这篇内容真正成立的特征，而不是重复第一轮长分析
- 明确哪些特征被第二轮数据验证，哪些被修正

## 注意事项
- 不要重做完整内容拆解
- 不要输出长篇分析
- 只保留后续做组间对比最有价值的特征
- 如果第一轮和第二轮冲突，以第二轮修正后的判断为准，同时保留“被修正点”
- 如果某项信息不足，明确写“信息不足”

## 输入说明
我会提供：
- 标题
- 数据水平分组
- 第一轮内容分析结果（无数据）
- 第二轮数据修正结果

## 输出要求

### 一、基础信息
- `标题`
- `数据水平分组`
- `媒介形式`：视频 / 图文 / 直播切片 / 录屏讲解 / 其他
- `内容类别`：教程型 / 观点型 / 资料型 / 案例型 / 复盘型 / 清单型 / 故事型 / 混合型 / 其他

### 二、选题特征
- `主题`
- `命题`
- `切口`
- `目标受众`
- `核心痛点`
- `收益承诺`

要求：
- 只提炼最核心的，不要展开长解释
- 用一句话或短语表达
- 每个字段后可加：`已验证 / 部分验证 / 未验证`

### 三、表达特征
- `内容类别`
- `标题标签`
- `开头标签`
- `结构标签`
- `表达风格标签`
- `互动设计标签`

要求：
- 标签尽量简洁、统一、可复用
- 如果没有明显互动设计，写 `无明显设计`
- 每个字段后可加：`已验证 / 部分验证 / 未验证 / 被推翻`
- 如果一个字段包含多个标签，统一用 `、` 分隔，不要混用逗号、斜杠或分号

### 四、机制特征
- `主要吸引机制`
- `主要信任机制`
- `主要获得机制`
- `主要沉淀机制`

要求：
- 每项只写 1 到 2 个最主要机制
- 用简洁表述，不要展开成长段
- 每个字段后可加：`已验证 / 部分验证 / 未验证 / 被推翻`
- 如果一个字段包含多个机制，统一用 `、` 分隔

### 五、被修正点
- `第一轮高估点`
- `第一轮低估点`
- `被推翻的判断`
- `伪特征候选`
- `最终应以什么判断为准`

要求：
- 如果有多个点，统一用 `、` 分隔
- 如果没有，写 `无`

## 输出格式
直接输出正式正文，不写额外说明，不要加代码块。
