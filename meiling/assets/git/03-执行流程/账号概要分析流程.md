# 账号概要分析流程

## 1. 读取账号基础信息

先打开：

- `07-记录表/账号库.csv`

找到目标账号那一行，读取以下字段：

- `账号ID`
- `昵称`
- `平台`
- `简介`
- `粉丝数`
- `获赞数`
- `标签`
- `主页链接`
- `图片说明路径`
- `内容列表路径`
- `人工先验说明路径`

我方当前概要固定读取：

- `05-我方资料/我方当前概要.md`

## 2. 执行输入检查（内部）

按下面这 4 项逐项检查：

1. 图片说明
2. 内容列表
3. 人工先验说明
4. 我方当前概要

每项只检查 3 件事：

- `是否提供`
- `存放路径`
- `是否可用`

最后判断：

- `当前最关键的信息缺口`
- `是否允许低置信度继续`

说明：

- 这一步是 **内部执行步骤**，用于判断能不能继续，不属于交付给用户的分析报告内容

## 3. 缺资料时的处理规则

如果缺资料，按下面规则处理：

1. `图片说明` 缺失或不可用
   - 提示用户补商品截图、社群截图、商品介绍截图、主页截图或其他补充信息图片
   - 同时标记：模式层中的产品判断、账号层中的主页气质/封面风格/栏目感判断都会降置信度
2. `内容列表` 缺失或不可用
   - 停止本次概要分析
   - 直接提示用户补 `内容列表.csv`
   - 原因：没有内容列表，内容层无法成立
3. `人工先验说明` 缺失或不可用
   - 可以继续
   - 但提示用户：模式层中的商业判断会偏弱
4. `我方当前概要` 缺失或不可用
   - 可以继续
   - 但提示用户：启发层只能输出通用启发

如果检查结果中：

- `是否允许低置信度继续 = 否`
  - 那就先不调用 prompt
  - 直接在对话框里告诉用户当前缺什么，并等待用户补资料
- `是否允许低置信度继续 = 是`
  - 那就带着缺口继续执行
  - 但只在分析正文中对应字段写明 `信息不足`
  - 不要在交付文档里单独增加“信息缺口与补充建议”章节

## 4. 组装输入

调用 prompt 前，按固定顺序组装输入。

### 4.1 账号基础信息

来自 `账号库.csv`，输入这些字段：

- `账号ID`
- `昵称`
- `平台`
- `简介`
- `粉丝数`
- `获赞数`
- `标签`
- `主页链接`

### 4.2 图片说明

来自 `图片说明路径` 对应目录。

只提炼与分析直接相关的图片线索，优先包括：

- 商品或服务名称
- 价格
- 商品层级
- 交付形式
- 是否有社群 / 课程 / 资料 / 线下课 / 顾问线索
- 主页昵称
- 主页简介
- 粉丝数 / 获赞数
- 封面风格
- 栏目感
- 主页整体气质

不要把整张图原样长篇转写进去，只提炼和商业判断、主页呈现判断有关的信息。

### 4.4 内容列表

来自 `内容列表路径` 对应的 `csv`。

直接提取以下字段并整表输入：

- `标题`
- `媒介形式`
- `点赞数`
- `收藏数`
- `评论数`
- `分享数`
- `核心互动数`
- `数据水平`
- `发布时间`
- `发布时间区间`

不做高表现筛选，不做近期筛选，不做整体观察总结。

### 4.5 人工先验说明

来自 `人工先验说明路径`。

直接输入整理后的文字，不再二次拆分。

### 4.6 我方当前概要

固定来自：

- `05-我方资料/我方当前概要.md`

直接输入整理后的文字，不再二次拆分。

## 5. 调用 prompt

调用：

- `04-提示词/账号概要分析提示词.md`

输入顺序固定为：

1. 账号基础信息
2. 图片说明
3. 内容列表摘要
4. 人工先验说明
5. 我方当前概要

如果有缺口但允许继续，就在输入前明确补一句：

- `以下材料存在缺口。请在对应分析字段内明确写出信息不足，不要硬猜，也不要输出单独的信息缺口章节。`

## 6. 保存结果

将输出保存到：

- `08-对标账号/<平台-账号ID-账号昵称>/概要分析.md`

保存要求：

- 文档标题固定为：`<昵称>账号概要分析`
- 交付文档只保留分析正文，不写这些过程型内容：
  - 是否建议进入详细分析
  - 信息缺口与补充建议
- 如果你想保留执行过程，可单独保存内部文档，但不要混入交付报告

## 7. 对话框反馈用户

完成报告后，在对话框中单独告诉用户：

- 这次是否建议进入详细分析
- 如果继续深挖，最该补的 1 到 3 项信息
- 如果本次带缺口继续，也在对话框中提示

## 8. 回写账号库

完成后回写 `07-记录表/账号库.csv` 的以下字段：

- `是否已概要分析` = 是
- `备注`：补一句本次概要分析已完成

如果后续你给 `账号库.csv` 新增了这些字段，再继续回写：

- `概要分析路径`
- `最近分析时间`
- `是否建议进入详细分析`
