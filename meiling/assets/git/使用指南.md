# 使用指南

## 1. 这份指南是干什么的

这份指南不是解释系统怎么设计的，而是告诉你：

- 先看什么
- 从哪里开始
- 不同任务分别该用哪些文件
- Trae 里可以调哪些 skill

如果你想看这套系统为什么这么设计，去看：

- `01-系统层/系统设计方法论.md`
- `01-系统层/文件设计规范.md`
- `01-系统层/文档书写规范.md`

## 2. 第一次使用时先看什么

第一次接手这套系统时，建议按下面顺序看：

1. 先看 `使用指南.md`
2. 再看 `01-系统层/系统设计方法论.md`
3. 再看 `05-我方资料/` 里的 4 个我方资料文件
4. 再看 `07-记录表/` 里的几张主表
5. 再进入对应流程和 skill

## 3. 先从哪里开始

如果你是从 0 开始搭系统，建议按下面顺序推进：

1. 先完成 `05-我方资料/我方商业模式.md`
2. 再完成 `05-我方资料/我方自媒体模式.md`
3. 再补 `05-我方资料/我方当前概要.md`
4. 再完善 `07-记录表/我方账号库.csv`
5. 再完善 `07-记录表/我方内容库.csv`
6. 再进入对标研究、选题、内容生产和复盘

## 4. 不同任务看哪里

先记住一个总规则：

- 本项目下所有 skill 都是显式调用
- 调用格式统一是 `/skill-name`
- 不要依赖自然语言自动触发
- 真正执行时，以对应的 `03-执行流程/*.md` 为准

**注意：**
- Trae 和 Claude Code 都可以调用这些 skill
- Trae 中调用：直接使用 `/skill-name`
- Claude Code 中调用：在 Skills 菜单中选择，或直接输入 `/skill-name`
- 两者使用的是同一套 skill 文件，执行逻辑完全一致

## 5. 文件夹分别放什么

- `01-系统层`
  - 放系统上位说明
- `02-业务方法论`
  - 放判断标准和分析方法
- `03-执行流程`
  - 放具体执行顺序
- `04-提示词`
  - 放单步生成提示词
- `05-我方资料`
  - 放我方长期维护资料
- `06-沉淀结论`
  - 放沉淀后的阶段性结论
- `07-记录表`
  - 放结构化记录表
- `08-对标账号`
  - 放对标账号样本
- `09-对标内容`
  - 放对标内容样本
- `.trae/skills`
  - 放 Trae 的 skill 文件（供参考和备份）
  - Claude Code 的 skill 已保存在系统账号中

## 6. 使用时的几个原则

- 先看流程，再调 skill，不要跳过流程直接乱调
- skill 统一通过 `/skill-name` 显式调用，不要等它自然语言自动触发
- Trae 和 Claude Code 都可以调用 skill，两者执行逻辑完全一致
- 先补资料，再做判断，不要让 AI 在缺资料时硬写
- 先回写记录表，再开始下一轮，不要让结果散在对话里
- 同类内容尽量放回固定目录，不要新开一堆临时文件

## 7. 一句话理解

这套系统的默认使用顺序是：

- 先明确我方资料
- 再按流程推进任务
- 再通过 skill 调度执行（Trae 或 Claude Code 均可）
- 最后把结果回写并沉淀
